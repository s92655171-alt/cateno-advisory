Local content manager

Edit the website content below, then download content.json. Replace the existing content.json in the project root and in nextjs/public/, then redeploy. This editor is a local tool; it does not publish changes automatically and should not be uploaded as a public admin area.

Changes are stored in this browser until exported.

How to publish your changes

  1. Click Download content.json.
  2. Replace cateno-advisory/content.json with the downloaded file.
  3. Also replace cateno-advisory/nextjs/public/content.json with the same file.
  4. Run the website locally to check it, then deploy the updated project to your hosting provider.

Note: Text changes apply to the editable fields below. Some page headings, legal text and layout elements are still maintained in the source files and need a code change.
